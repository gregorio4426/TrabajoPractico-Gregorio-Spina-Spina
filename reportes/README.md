# Reportes del trabajo práctico

Los reportes se generan cuando haya datos reales exportados desde Plane.
No se incluyen números ficticios ni se simula un historial que todavía no existe.

Archivos previstos:
- `tareas-normalizadas.json`
- `costos.md`
- `brooks.md`
- `reporte-po.md` / `reporte-po.html`
- `historico-costos.json`
- `historico-po.json`

El primer análisis de Plane queda pendiente de crear el workspace/proyecto, definir
su slug y configurar una API key en el entorno local.
